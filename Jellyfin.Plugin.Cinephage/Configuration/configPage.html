Cinephage Requests

Gebruikers kunnen films en series (per seizoen) aanvragen vanuit de Jellyfin-zoekpagina. Verzoeken worden direct goedgekeurd in Cinephage; wie wat aanvroeg zie je onder Cinephage-verzoeken in het dashboardmenu.

De Main API-key uit Cinephage (Instellingen → Systeem → API keys), niet de streaming-key.
